# ディレクトリ・ファイル一覧

AGENTS.md: リポジトリの目的、ディレクトリ構造、作業規約。
templates/: 問題ごとの作業ディレクトリへコピーして使う雛形。
templates/AGENTS.md: 数学問題を解く反復工程、方針ファイルの役割、コピー先の記録配置。
templates/dev_mcp/: コピー先で使う開発用MCPの実装と起動構成。
docs/: 仕様・設計・計画・手順など、リポジトリの判断基準と記録を置く。
docs/README.md: `docs/` の目的、基本構成、文書の使い分け。
docs/目次.md: `docs/` のディレクトリと主要文書の一覧、探し方。
docs/手順/: 作業・運用・確認の手順。
docs/仕様/: 機能と要件。
docs/仕様/workflow_mcp.md: ターン指定のreject操作とMCPの実行環境。
docs/計画/: 今後の作業順序、成果物、依存関係、完了条件。

# ファイルの探し方

まず `docs/README.md` で文書区分と使い分けを確認し、この一覧から関連する主要ディレクトリ・文書を探す。文書は内容に応じて `docs/README.md` に記載された基本構成へ配置する。
